📖 Cipher Mechanics & Theory

Theoretical foundations, mathematical equations, and worked examples for classical and modern ciphers.

1. The Caesar Shift Cipher

Substitution

The Caesar cipher shifts each letter in the alphabet by a fixed integer $k$ between 1 and 25. Because the English alphabet wraps around from Z back to A, this is computed using modular arithmetic:

Encryption: C = (P + k) mod 26
Decryption: P = (C - k + 26) mod 26
Example with Shift k = 3:
Plaintext: H E L L O
H(7) + 3 = K(10) | E(4) + 3 = H(7) | L(11) + 3 = O(14) | O(14) + 3 = R(17)
Ciphertext: K H O O R

Cryptanalysis Tip: There are only 25 possible non-trivial shifts. A computer script can check all 25 shifts simultaneously in less than 1 millisecond.

2. The Atbash Mirror Cipher

Reciprocal

Originally created for the Hebrew alphabet, Atbash is a monoalphabetic substitution cipher where the alphabet is inverted: the first letter maps to the last letter, the second maps to the second-to-last, and so on.

Mapping Equation: Index_C = 25 - Index_P
[A ↔ Z] [B ↔ Y] [C ↔ X] [D ↔ W] [E ↔ V] ... [M ↔ N]
Example:
Plaintext: F L A G
F ↔ U, L ↔ O, A ↔ Z, G ↔ T
Ciphertext: U O Z T

Self-Inverting Property: Encrypting and decrypting are the exact same operation. Passing ciphertext through the Atbash transform a second time restores the plaintext.

3. The Vigenère Cipher

Polyalphabetic

The Vigenère cipher resists simple frequency analysis by using a repeating keyword where each letter dictates a different Caesar shift for each character of the message.

Shift_i = (Key[i % len(Key)] - 'A')
Decryption: P_i = (C_i - Shift_i + 26) mod 26
Example with Key "CAT" (C=2, A=0, T=19):
Plaintext: A T T A C K
Keystream: C A T C A T
A(0)+2=C | T(19)+0=T | T(19)+19=M | A(0)+2=C | C(2)+0=C | K(10)+19=D
Ciphertext: C T M C C D

Notice how the two 'T's in "ATTACK" encrypted to two different letters ('T' and 'M')!

4. Encodings: Hex & Base64

Data Representation

Encoding is not encryption; it provides representation rather than confidentiality. Attackers and defenders constantly convert bytes across formats:

  • Hexadecimal (Base16): Uses digits 0-9 and a-f. Every single byte is represented by exactly two hex characters (e.g., 'A' = 65 = 0x41).
  • Base64: Takes 3 bytes (24 bits) and groups them into four 6-bit numbers, mapped to A-Z, a-z, 0-9, +, /. If bytes do not divide evenly by 3, '=' padding characters are appended to the end.
Text: "FLAG"
Hex: 466c6167
Base64: RkxBRw==

5. RSA Public-Key Cryptography

Asymmetric Math

RSA relies on the mathematical difficulty of factoring the product of two large prime numbers. The mathematical mechanics follow a specific order:

1. Key Generation
Select primes: p, q
Modulus: n = p * q
Totient: φ(n) = (p-1)*(q-1)
2. Private Key (d)
Choose e coprime to φ(n)
Solve for d:
(d * e) ≡ 1 (mod φ(n))
3. Decryption
Cipher integer: c
Recover message m:
m = (c^d) mod n

Caesar Cipher 26-Shift Brute-Forcer

Tests all 26 possible shifts simultaneously and prints the output for each shift. 

def brute_force_caesar(cipher_text):
    for shift in range(26):
        plain = []
        for char in cipher_text:
            if char.isalpha():
                base = ord('A') if char.isupper() else ord('a')
                # Shift backwards to decrypt
                plain.append(chr((ord(char) - base - shift) % 26 + base))
            else:
                plain.append(char)
        print(f"[Shift {shift:02d}]: {''.join(plain)}")

# Generic practice sample ("THE QUICK BROWN FOX..." shifted by 3):

Atbash Reciprocal Inverter

Translates every letter to its inverse counterpart across the alphabet. 

def solve_atbash(cipher_text):
    result = []
    for char in cipher_text:
        if 'A' <= char <= 'Z':
            result.append(chr(ord('Z') - (ord(char) - ord('A'))))
        elif 'a' <= char <= 'z':
            result.append(chr(ord('z') - (ord(char) - ord('a'))))
        else:
            result.append(char)
    return "".join(result)

Vigenère Decryption Routine

Decrypts polyalphabetic ciphertext using a known or suspected keyword. 

def decrypt_vigenere(cipher_text, key):
    key = key.upper()
    plain = []
    key_idx = 0
    for char in cipher_text:
        if char.isalpha():
            base = ord('A') if char.isupper() else ord('a')
            shift = ord(key[key_idx % len(key)]) - ord('A')
            plain.append(chr((ord(char) - base - shift + 26) % 26 + base))
            key_idx += 1
        else:
            plain.append(char)
    return "".join(plain)

# Generic practice sample ("ATTACK AT DAWN" encrypted with key "LEMON"):
sample_cipher = "LXFOPV EF RNHR"
sample_key = "LEMON"
print("Decoded sample:", decrypt_vigenere(sample_cipher, sample_key))

function solveVigenere(cipher, key) {
  key = key.toUpperCase();
  let kIdx = 0;
  return cipher.replace(/[a-zA-Z]/g, c => {
    let isUpper = c <= 'Z';
    let base = isUpper ? 65 : 97;
    let shift = key.charCodeAt(kIdx % key.length) - 65;
    kIdx++;
    return String.fromCharCode(((c.charCodeAt(0) - base - shift + 26) % 26) + base);
  });
}

function decodeHexBase64(hexStr) {
  // 1. Convert pairs of hex characters into an ASCII string
  const base64Str = hexStr.match(/.{1,2}/g)
    .map(byte => String.fromCharCode(parseInt(byte, 16)))
    .join('');
  console.log("Step 1 (Base64 string):", base64Str);

  // 2. Decode the Base64 string with the browser's native atob() function
  const plain = atob(base64Str);
  return plain;
}

JS Console: RSA Private Key Finder & Decrypter

Searches for modular inverse `d` and executes BigInt modular exponentiation: 

function solveRSA(p, q, e, c) {
  const n = p * q;
  const phi = (p - 1) * (q - 1);

  // 1. Find private key exponent d where (d * e) % phi === 1
  let d = 1;
  while ((d * e) % phi !== 1) {
    d++;
  }
  console.log("Computed Private Key d:", d);

  // 2. Compute m = (c ^ d) mod n using BigInt
  let b = BigInt(c), exp = BigInt(d), mod = BigInt(n);
  let result = 1n;
  b = b % mod;
  while (exp > 0n) {
    if (exp % 2n === 1n) result = (result * b) % mod;
    b = (b * b) % mod;
    exp = exp / 2n;
  }

  const m = Number(result);
  console.log("Decrypted Message Integer m:", m);
  return { m, d };
}
